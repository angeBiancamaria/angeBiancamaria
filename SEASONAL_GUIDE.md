# Thèmes saisonniers v3 — effets renforcés

Les illustrations existantes sont conservées : carte de Corse et cibles d'objectifs.
Les variantes disposent maintenant d'un cadre lumineux, d'une étiquette saisonnière,
de grandes décorations thématiques et d'animations SVG légères.
La bannière « hello i'm ange » reste unique. Les citations et le Snake sont conservés.

## Tester
Actions → Seasonal profile theme → Run workflow → preview_theme.
Sélectionner halloween, christmas, birthday, summer, spring, winter, autumn ou easter.
Le prochain lancement automatique revient à la saison du jour.

## Important
GitHub peut mettre les SVG en cache : actualiser après quelques minutes.
Les animations SVG peuvent dépendre du moteur de rendu et des préférences de mouvement.
Le workflow ne modifie pas encore les couleurs du Snake, qui dépend de sa propre branche `output`.
Pour ne pas écraser le dépôt, copier les fichiers du ZIP en conservant vos changements récents.
